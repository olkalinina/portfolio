# Site icons

Line icons (24x24, 2px stroke). Use them with the `.ic` class from theme.css so they take the text colour and are 24px:

    <span class="ic ic-bulb" aria-hidden="true"></span>

| Class | File | Used for |
|---|---|---|
| ic-data | data.svg | "By the numbers" callouts |
| ic-bulb | lightbulb.svg | Insights: "The broader point", "3 questions" |
| ic-dark-pattern | dark-pattern.svg | "Dark pattern detected" and warning callouts |
| ic-brain | brain.svg | "What this redesign is about", "Core design decisions" |
| ic-site-map | site-map.svg | Information architecture / redesign proposal |
| ic-rocket | rocket.svg | "Coming soon" |
| ic-announcement, ic-bell, ic-coins, ic-location, ic-message, ic-star, ic-thumbs-up | same names | Not used yet |
